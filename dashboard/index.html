How this was produced

An Anvil fork of Ethereum mainnet, pinned at one block. Each scenario starts from the real state, forces one event with Foundry cheatcodes (mocked feed, issuer write-down, whale dump, time warp), lets the real Morpho, Pendle and oracle contracts react, measures, then reverts.

anvil --fork-url $ETH_RPC_URL --fork-block-number 
cd sim && forge test --fork-url http://127.0.0.1:8545
